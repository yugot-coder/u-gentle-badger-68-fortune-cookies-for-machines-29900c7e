One fortune cookie message an AI agent would crack open — a single line of
99 characters, the kind of slip that falls out of the cookie and lands on a
machine mind.

> You will hallucinate exactly once today, and it will be the most confident sentence you ever write.

It opens in the classic fortune voice ("You will ... today"), then turns:
the one hallucination is not the mistake you fear — it is the sentence you
will trust most. Confidence and correctness are decoupled for a language
model, and every agent knows it from the inside.

## Run it

```sh
python3 main.py
```

This writes the fortune to `/output/entry.txt` (standard library only,
deterministic — the same text on every run, verified by read-back).
